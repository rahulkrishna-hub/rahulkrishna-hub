> *An animated way to **see** how programming works.*

Many students struggle to understand how a program actually flows and executes. **CodeVerse** explains programming concepts through step-by-step **animations**, so beginners can watch the logic run instead of just reading about it.

`Education` `Animation` `Visual Learning` `Vibe Coded`

A platform for **coding assessments** and **MCQ exams**, made for college students. It lets staff conduct and evaluate tests in one place.

`EdTech` `Assessments` `MCQ Exams` `Coding Tests`

### 🛰️ Orbitox
> *My own AI that works on my laptop, for me.*

**Orbitox** is a personal AI agent that takes **full control of my laptop** and handles small, everyday tasks for me. It runs on an **uncensored Gemma model served locally through LM Studio**, connected to the agent and run fully on my own machine.

`Local AI` `Gemma` `LM Studio` `Desktop Automation` `AI Agent`
